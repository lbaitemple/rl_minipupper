# Mini Pupper 4 — Reinforcement Learning tutorial bundle

## Start here
1. Unzip the package.
2. Open `index.html` in Chrome or Safari.
3. Use the eight lesson links to navigate; they are regular HTML anchors.
4. Each code example includes a Copy button.
5. Lesson 4 illustrates MuJoCo Viewer and the XML-loading error.
6. Lesson 6 includes Google Colab interface illustrations.

## Files
- `index.html`: offline tutorial (open this first)
- `assets/`: all figures/images embedded by the HTML
- `notebooks/MiniPupper4_RL_Colab.ipynb`: Colab notebook
- `docs/MuJoCo_Mini_Pupper_4_Tutorial_Guide.pdf`: earlier six-section PDF guide
- `PUBLISH_TO_GITHUB.md`: instructions if you wish to publish this package to GitHub

Note: The interface figures are illustrations, not actual application screenshots. Colab GPU training depends on the available NVIDIA/CUDA runtime. Full GPU training was not executed in this environment.

## Hands-on exercises
Each of the eight HTML lessons now includes a mini exercise, an expected result, and a collapsible hint. The exercises are designed for programmers and can be completed incrementally.
